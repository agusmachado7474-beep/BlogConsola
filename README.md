# Blog consola

Este es un espacio para publicar contenido relacionado con el proyecto de blog por consola.

## Descripción

El objetivo de este repositorio es crear una aplicación de blog que funcione desde la terminal, con una interfaz simple y una estructura organizada.

## Funcionalidades previstas

- Crear publicaciones
- Listar entradas
- Buscar por título
- Organizar contenido por categorías
- Mantener el proyecto en Python con una estructura clara
